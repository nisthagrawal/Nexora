# Open-source usage and research references

| Project | Planned purpose | Current use | Restriction |
|---|---|---|---|
| PaddleOCR | OCR detection/recognition | adapter target only | review its licence before redistribution |
| PassportEye | MRZ extraction/parsing | adapter target only | parsing is not passport authentication |
| DeepFace | face-document comparison | adapter target only | biometric consent and model licence required |
| CAT-Net | forensic localisation candidate | not bundled | check code/weight licence and dependencies |
| DocTamper / TruFor / ManTraNet | research references | not bundled | do not make mandatory or redistribute without licence review |

Nexora independently defines its common evidence schema, contradiction logic, validation wiring, and risk presentation. Dataset/model use must be recorded with version, licence and attribution before release.
